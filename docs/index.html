Como conseguir tu clave gratis
  1. Entra a aistudio.google.com/api-keys e inicia sesion con tu cuenta de Google.
  2. Toca el boton "Create API key" / "Crear clave de API".
  3. Ponele un nombre a la clave (podes dejar el que sugiere por defecto).
  4. Elegi el proyecto de Gemini por defecto (no hace falta crear uno nuevo la primera vez).
  5. Toca "Create key" para generarla.
  6. Copia la clave y pegala en el campo de arriba.

Es gratis, pero tiene un limite de usos por dia — para la expo alcanza de sobra.
